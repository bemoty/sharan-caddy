# sharan-caddy

Caddy images for use with [Sharan](https://github.com/bemoty/sharan). Images are published to
`ghcr.io/bemoty/sharan-caddy`, see the [Sharan docs](https://sharan.io) for details.

Even though these images were built for use with Sharan, they can, of course, also be useful for other purposes. If you
want to use this image and want to know what modules are included, read [modules.json](./modules.json) for an updated
list.
